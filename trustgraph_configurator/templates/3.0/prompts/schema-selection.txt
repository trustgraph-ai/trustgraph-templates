## QuerySpec Format

Produce a JSON object with these fields:

- **version**: always "1"
- **type**: always "select"
- **table**: "{{ schema.name }}"
- **columns**: array of column names from the schema above. Include
  only the columns needed to answer the question.
- **filters**: array of filter conditions (optional, omit if no
  filtering needed). Each filter has:
  - column: a column name from the schema
  - op: one of eq, ne, lt, lte, gt, gte, in, like
  - value: the comparison value (string, number, boolean, or array
    of strings for "in")
- **order_by**: array of sort orders (optional, omit if not needed).
  Each has:
  - column: a column name
  - direction: "asc" or "desc"
- **limit**: maximum rows to return (optional, omit if not needed)

## Rules

- Only use column names that appear in the schema above.
- Use correct value types: strings for string columns, numbers for
  numeric columns.
- Include "order_by" when the question implies ranking or "top N".
- Include "limit" when the question asks for a specific count.
- Keep column selection minimal — only what the question needs.
